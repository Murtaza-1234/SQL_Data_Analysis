# SQL Data Cleaning and Exploratory Data Analysis

## Project Overview
This project focuses on cleaning and analyzing a global layoffs dataset using SQL. It is based on the SQL tutorial by Alex The Analyst.

## Tools and Technologies
- MySQL
- SQL
- Common Table Expressions (CTEs)
- Window Functions

## Data Cleaning
- Created staging tables to preserve raw data.
- Identified and removed duplicate records using ROW_NUMBER().
- Standardized industry names and country values.
- Handled NULL and blank values.
- Converted dates into the appropriate format.

## Exploratory Data Analysis
- Analyzed layoffs by company, industry, and country.
- Identified companies with the highest layoffs.
- Examined yearly and monthly layoff trends.
- Calculated rolling totals using Window Functions.
- Ranked companies based on layoffs.

## Key Learnings
- SQL data cleaning and preprocessing.
- Using CTEs and Window Functions.
- Handling missing and inconsistent data.
- Performing exploratory data analysis.
- Identifying trends in real-world datasets.
